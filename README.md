# Önder Med - İlaç Danışmanı

Önder Med, sağlık profesyonelleri ve kullanıcılar için geliştirilmiş bir ilaç bilgi ve danışma uygulamasıdır.

## Özellikler

- İlaç bilgisi sorgulama
- İlaç etkileşimleri kontrolü
- Belirti analizi
- Hasta şikayet değerlendirme
- Google Gemini AI destekli yanıtlar

## Kurulum

1. Programı indirin
2. Kurulum sihirbazını takip edin
3. API anahtarınızı ayarlar bölümünden girin
4. Kullanmaya başlayın

## Kullanım

- İlaç bilgisi için ilacın adını girin
- İlaç etkileşimleri için iki ilacı karşılaştırın
- Belirtilerinizi analiz edin
- Şikayetlerinizi değerlendirin

## Önemli Not

Bu uygulama bir sağlık profesyonelinin yerini tutmaz. 
Tüm tıbbi kararlar için mutlaka bir sağlık profesyoneline danışınız.

## Teknik Gereksinimler

- Windows 10 veya üzeri
- Internet bağlantısı
- Google Gemini API anahtarı
